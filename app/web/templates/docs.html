快速开始

  1. 注册账户，注册后立即启用，无需人工审核。
  2. 在 API 密钥 页面自助签发密钥，完整密钥只显示一次，请立即保存。
  3. 在 积分 页面兑换积分（兑换码或管理员加分）。
  4. 把客户端的 base_url 设为 {{ app_base_url }}/v1，发起第一次请求：

认证与密钥

使用 Authorization: Bearer lapi_xxx 或 X-API-Key: lapi_xxx 携带密钥；业务接口中标为“匿名可用”的无需认证。

  • 权限按 scope 精确匹配。自助密钥包含 models:read、chat:completions、responses:create、images:generate，默认每分钟 60 次。已有密钥保持原权限，新增图像权限需重新签发或由管理员授权。
  • 每个账户最多保留 20 个有效密钥；所有密钥共用账户积分。
  • 账户停用后，名下密钥同步失效；业务服务权限由管理员单独配置。
  • 密钥只应放在服务端或受信任的本地应用里，不要写进前端代码或公开仓库。

图像生成

POST /v1/images/generations 使用 images:generate 权限与模型白名单，支持 gpt-image-2、gpt-image-1.5。登录后试用、预览与下载 →

JSON 必须显式指定 model 和非空 prompt（最多 32,000 字符）。quality 支持 low / medium / high，省略或 auto 均采用 medium；size 支持 1024x1024 / 1024x1536 / 1536x1024，省略或 auto 均采用 1024x1024。n 仅支持整数 1，输出格式仅 PNG。返回 data[0].b64_json、分模态 usage 与响应头 X-Request-ID。

不支持编辑、批量、透明背景、stream、tools、partial_images、response_format 或其他额外参数；额外字段返回 400。遇到待核请保留请求 ID，重试会产生一次新调用。

cURL · Images API
curl {{ app_base_url }}/v1/images/generations \
  -H "Authorization: Bearer $LUOMO_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"gpt-image-2","prompt":"一列穿过星空的列车","quality":"low","size":"1024x1024","n":1}'
Python · OpenAI SDK
import base64
import os
from openai import OpenAI

client = OpenAI(base_url="{{ app_base_url }}/v1", api_key=os.environ["LUOMO_API_KEY"])
result = client.images.generate(
    model="gpt-image-2", prompt="一列穿过星空的列车",
    quality="low", size="1024x1024", n=1, output_format="png",
)
with open("generated.png", "wb") as image:
    image.write(base64.b64decode(result.data[0].b64_json))

先按输入与输出上界冻结预算，随后按官方 Standard 分模态价格与实际用量结算。取消或超时后可能已在生成，缺失/矛盾用量或超出预算会保留本笔冻结并进入待核，不根据图片大小猜费用。有效图片与可计价回执超预算时仍可下载，响应头 X-Credit-Status: reconciliation_required 表示保留真实费用待核；已知费用超出冻结总额后，后续生成返回 409。详见图像价格。

积分与计费

生成调用按 OpenAI 官方 Standard 单价结算：¥1 = 100 积分，$1 = 720 积分，精确到六位小数。

  • 每次生成先按输入估算和输出上限冻结预算，完成后按上游回报的真实 token 结算，多退少补。
  • 缓存命中与长上下文使用对应价格档位；读取模型目录不收费。
  • 余额不足时返回 402；上游在生成前就拒绝的请求（如上游凭据暂不可用、限流）不扣费，冻结立即释放；缺少可靠用量的其他请求只保留本笔冻结并进入待核。
  • 兑换码、管理员加分与在线充值（开放后）共用同一余额。

登录与账户安全

  • 网页登录 12 小时有效；退出登录后，这个会话会立即在服务端失效。
  • 在 账户与安全 可以修改密码、查看登录设备并让其他设备退出。修改密码后，其他设备会自动退出。
  • 忘记密码时，在登录页点“忘记密码”，通过邮件里的一次性链接（60 分钟内有效）重置；重置后所有设备都需要重新登录。
  • 网页会话与 API 密钥相互独立：改密码不会让 API 密钥失效，需要时请在密钥页单独撤销。
