每个接口负责什么

  

    
接口用途密钥权限边界

    
      
GET /v1/models读取当前密钥允许的模型models:read不消耗积分

      
POST /v1/chat/completions常见客户端聊天，支持 SSE 流式chat:completionsmessages 格式

      
POST /v1/responsesResponses 协议，支持 SSE 流式responses:createinput 格式；不支持远端会话检索

      
图像输入{% if image_input_enabled() %}已开放：在 messages / input 中附带 image_url 或 input_image（https 或 base64，每次最多 16 张），仅限标注“图像输入”的模型。{% else %}暂未开放；目录中的“图像输入”只表示模型本身支持。{% endif %}

      
POST /v1/images/generations文生图，每次一张 PNGimages:generate{{ "已开放" if catalog.image_generation_enabled else "暂未开放" }} · 参数与示例

      
图像编辑 / 音频 / embeddings / 文件暂未开放。

    
  

  
新密钥同时受协议权限和模型白名单约束；旧版已授予的 CodexProxy 权限保持兼容。每分钟请求数、日/月配额和 UTC 有效期均由网关检查，失败和取消的请求也计入次数。






  
遇到错误时
完整错误表

  

    
状态码先检查

    
      
400JSON 格式、模型 ID、messages / input 是否与所选协议一致。

      
401密钥无效或已撤销，检查 Authorization: Bearer 头。

      
402积分不足；到积分页兑换后重试。

      
403密钥过期、账户停用，或模型 / 协议权限不足。

      
429请求频率、日/月配额或上游限制；按 Retry-After（若有）等待。

      
502 / 504上游失败或超时；保留 X-Request-ID，在用量页定位。

    
  

  
流式连接建立后，错误也可能出现在 SSE 事件里；HTTP 200 不能单独作为完成标志。
